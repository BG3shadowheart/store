CHARACTER ART
=============
By default each section shows a random SFW anime picture from the free nekos.best API
(artist credit is shown under the picture). To use your own art instead, save files here:

  anemo.png  geo.png  electro.png  dendro.png  hydro.png  pyro.png  cryo.png

(.png .webp .avif .jpg all work). Portrait images, ~1200 x 1600 px, work best;
transparent PNG cut-outs look the most like the Genshin site.
Only use art you have the rights to use.
